# OpenClaw Linux catalog links with a saved Gateway

Stock OpenClaw 2026.11.10 ran from the published x64 AppImage. A fresh saved Direct profile used the Gateway's token through a file-backed SecretRef. The namespace had only a loopback interface. The installed XDG handler accepted each URL generated by the published agent-deeplinks 0.1.44 package.

The same native process requested each exact Dashboard path. The Gateway admitted the operator as `openclaw-linux`, mode `ui`, with `auth=token` after each navigation. The test recorded zero model requests and zero registry writes. It selected no install or Add control.

- The plugin screen requested the Discord detail record and showed **Plugin details are unavailable** when the offline cache returned 404 for the detail endpoint.
- The skill link opened **Skills**. Its ClawHub trending request received a cache 404, and the Weather detail did not appear.
- The template link showed **Page not found**. In this version the Templates route returns that page until the Gateway enables the Templates lab.
