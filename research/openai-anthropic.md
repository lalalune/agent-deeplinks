## Parameters and prerequisites

- **Codex desktop** accepts `prompt`, absolute local directory `path`, and `originUrl` to match a Git remote to an existing workspace. `path` resolves first when both workspace options are provided. `codex://new` requires at least one supported parameter. The documented composer holds the prompt until the user sends it. [ChatGPT desktop commands](https://learn.chatgpt.com/docs/reference/commands#deep-links)
- **ChatGPT desktop** uses `codex://threads/new` with `mode=chat`. The web handoff code validates `chat`, `work`, and `codex` and assigns `mode` on newly composed threads. The public desktop command reference documents the base link without a `mode` option. [First-party web handoff asset](https://chatgpt.com/cdn/assets/617936.82c33d1781.js), [Desktop commands](https://learn.chatgpt.com/docs/reference/commands#deep-links)
- **ChatGPT web** reads `q` or `m` on the root path. Its current client checks `params.has("disable_auto_send")` before auto-submission. This is shipped behavior and can change as the web client is updated. [ChatGPT web client asset](https://chatgpt.com/cdn/assets/646436.8f73ec6517.js)
- **Claude desktop** accepts `q` for a chat draft. Claude Code Desktop accepts `q` or its alias `prompt`, plus optional absolute `folder` that requires confirmation in Claude. Desktop prompts are truncated at approximately 14,000 characters. [Claude Desktop deeplinks](https://support.claude.com/en/articles/14729294-open-claude-desktop-with-a-link)
- **Claude Code CLI** accepts `q` up to 5,000 characters, absolute local `cwd`, or a GitHub `repo` of the form `owner/name`. `cwd` takes precedence. A link without a known repository opens the home directory. Claude Code installs its handler during interactive use and leaves the incoming prompt for review. [Claude Code deeplinks](https://code.claude.com/docs/en/deep-links)
- **Claude Code CLI test details**. The first macOS launch used installed CLI 2.1.220. Its live Terminal-backed process had `--deep-link-origin` and `--prefill-b64` with the exact decoded Unicode marker. A separate dispatch to the installed handler symlink resolving to 2.1.331 succeeded and the vendor’s Terminal launcher carried the exact second marker, including Unicode, ampersand, and plus. The computer-use tool excludes Terminal, so this verifies argument delivery to the CLI without observing its composer. No prompt was submitted.
- **Claude Code mobile** accepts `q` or `prompt`, optional `mode=plan|code` subject to the account’s access, a connected GitHub `repo` in `owner/name` form, and `branch` when a repository is supplied. Mobile ignores Desktop’s `folder` and `file`. `claude://code` opens the session list, and `claude://code/{session-id}` opens an existing session. All values must be URL-encoded. [Claude mobile deeplinks](https://support.claude.com/en/articles/14898120-open-the-claude-mobile-app-with-a-link)
- **Mobile platform evidence** can establish which URLs dispatch to an installed app. Device testing is still needed to establish how the app uses query data after dispatch. [ChatGPT iOS association](https://chatgpt.com/.well-known/apple-app-site-association), [ChatGPT Android association](https://chatgpt.com/.well-known/assetlinks.json), [Claude iOS association](https://claude.ai/.well-known/apple-app-site-association), [Claude Android association](https://claude.ai/.well-known/assetlinks.json)
- [Codex mobile handoff](https://chatgpt.com/app/codex), [OpenAI mobile documentation](https://learn.chatgpt.com/docs/mobile), [Install Claude for Android](https://support.claude.com/en/articles/9612887-install-claude-for-android)
- **Claude browser routing** uses `#no_universal_links` after the query. Apple's CDN lists that fragment as the first exclusion for production Claude app IDs, ahead of `/new` and `/code/*`. [Apple-cached Claude association](https://app-site-association.cdn-apple.com/a/v1/claude.ai)
- **Android test availability**. Both connected Android 35 emulators lacked installed ChatGPT, Claude, and Google Play Store apps. The two publishers’ current Digital Asset Links files name their production Android app packages and declare host association without path rules. The Android manifest and an installed app are required to confirm link routing independently of the vendor docs. [Android App Links](https://developer.android.com/training/app-links/about)
- [ChatGPT desktop app transition](https://help.openai.com/en/articles/20001276-moving-to-the-new-chatgpt-desktop-app), [Codex web](https://chatgpt.com/codex), [Claude Code cloud entry points](https://code.claude.com/docs/en/claude-code-on-the-web)

## Icon provenance

- `icons/chatgpt.svg` is the black Blossom SVG from OpenAI’s brand archive. [OpenAI design guidelines](https://openai.com/brand/), [OpenAI logo archive](https://cdn.openai.com/brand/openai-logos.zip)
- `icons/claude.svg` is the 24×24 orange Claude symbol provided as `claude-logo.svg` by Anthropic. [Claude Platform branding samples](https://platform.claude.com/docs/en/manage-claude/oauth-apps/branding-samples#download-the-logo)
- `icons/codex.svg` preserves the three original SVG paths from OpenAI’s monochrome Codex cloud and terminal glyph. The source is ChatGPT desktop 26.1117.41037, `app.asar → .vite/build/early-bootstrap-916-90e0adb52d70fbc5.js`, in the remote control authorization page. The same app ships a separate glossy color PNG named `codex-app-ga-logo.dfddfb85d7.png`. [Codex product page](https://openai.com/codex/)
- `icons/claude-code.svg` preserves the exact 24×16 pixel grid and palette of Anthropic’s Clawd `LookingAroundEyesOnly` Core frame. The source is Claude Desktop 6.28899.6, `app.asar → .vite/renderer/main_window/assets/clawdQuestEngine-CmSbmscl.js`. This repository serializes the vendor’s sprite data as standalone SVG paths. Anthropic’s documentation publishes a separate full wordmark. [Claude Code docs](https://code.claude.com/docs/en/overview)
