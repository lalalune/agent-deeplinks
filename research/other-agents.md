## Grok and Grok Bot

Grok chat and Grok Bot are separate products. The November 19 [Grok Bot deeplink documentation](https://docs.x.ai/grok-bot/deep-links) supersedes the older glossary's assessment. The draft is filled only when the destination composer is empty. Without an ID the signed-in user needs a primary Bot. The published first-party builder replaces C0/C1 controls, including line breaks, with spaces, rejects empty messages, caps the message at 1,000 UTF-16 units, and caps the encoded native URL at 2,048 characters. The HTTPS form launches the installed app, with a separate confirmation or install flow depending on platform. [Published builder JavaScript](https://docs.x.ai/_next/static/chunks/2908rqvp8ew4d.js), [Observed HTTPS handoff](https://cursor.com/grok-bot/link/v1/prompt?text=Deeplink%20verification).

The [official macOS download](https://x.ai/bot) resolved to Grok Bot 1.2.3 for Apple Silicon. The 159,560,653-byte DMG mounted read-only. Its bundle ID is `com.anysphere.sand`, its notarized Developer ID is Anysphere Incorporated (team `DCNK4UB866`), and the app declares `grokbot` and `sand` URL schemes. Strict signature verification and Gatekeeper assessment passed. LaunchServices accepted the documented prompt URL, and the signed app opened a window from the mounted image with a temporary profile. Upstream docs require a signed-in Bot for composer acceptance. The launch check did not establish whether the marker reached the composer. No sign-in or prompt submission was performed.

Grok's primary sources identify the browser and both phone apps. A platform association file establishes domain routing, while prompt-handling logic needs separate evidence. The HTTP query appeared specifically in the React Server Components payload as a page search parameter. That establishes delivery to the web client and leaves composer behavior unresolved. [Grok overview](https://docs.x.ai/grok/overview), [iOS association](https://grok.com/.well-known/apple-app-site-association), [Android association](https://grok.com/.well-known/assetlinks.json).

## Meta Muse and Kimi

Meta distinguishes its Muse personal agent from the Meta AI personal assistant. The personal agent has its own web product, Mac download, and mobile apps. [Meta Muse product page](https://ai.meta.com/muse/), [Meta Muse help](https://www.meta.com/en-gb/help/superintelligence/1331373868832401/), [iOS association](https://applink.muse.ai/.well-known/apple-app-site-association), [Android association](https://applink.muse.ai/.well-known/assetlinks.json).

Kimi Mac app bundle ID `com.moonshot.kimichat`, display version 3.2.27 and bundle version 3.2.27.25, declares `kimi` and `kimi-work` in `Contents/Info.plist`. The main bundle `Contents/Resources/app.asar` member `out/main/index.js` uses `kimi-work://home` as an OAuth callback return target and its operating-system dispatch routes that URL to `getKimiAgent().openPage()` after focusing the app window. The `kimi` scheme constructs an internal path from the location, including the original query and fragment. Composer routes need separate support evidence. REA found an integrity mismatch in the companion unpacked native module and its retry timed out. The plist and JavaScript parser/dispatch were checked directly, without executing package code. [Kimi overview](https://www.kimi.ai/help/getting-started/overview), [International iOS association](https://www.kimi.ai/.well-known/apple-app-site-association), [Regional iOS association](https://www.kimi.com/.well-known/apple-app-site-association).

## Hermes Agent and OpenClaw

Slop Cash and Slop Date integrate the Hermes skill installer. The installer accepts `official/…` for optional skills, `clawhub/…` for ClawHub, or an explicit repository path for bundled skills. The official example uses `official/security/1password`. Hermes documents a separate open-only route for an “Open Hermes” button. The Webapp is opt-in and uses its own browser authentication. [Hermes Desktop](https://hermes-agent.nousresearch.com/docs/user-guide/desktop#settings--onboarding), [Desktop install links](https://hermes-agent.nousresearch.com/docs/user-guide/features/skills#desktop-install-links), [Hermes Webapp](https://hermes-agent.nousresearch.com/docs/user-guide/desktop#use-the-desktop-workspace-from-a-browser).

Slop Cash and Slop Date ship the OpenClaw agent-action form. An unkeyed link opens a confirmation dialog, while a user-confirmed click starts the run. Current iOS source strips delivery settings before prompting. macOS strips them on the ordinary unkeyed route. Avoid keys and delivery in a public link builder. Upstream documents Gateway connection links for a separate connection review flow. [Shared macOS/iOS parser](https://github.com/openclaw/openclaw/blob/main/apps/shared/OpenClawKit/Sources/OpenClawKit/DeepLinks.swift), [macOS handler](https://github.com/openclaw/openclaw/blob/main/apps/macos/Sources/OpenClaw/DeepLinks.swift), [iOS handler](https://github.com/openclaw/openclaw/blob/main/apps/ios/Sources/Model/NodeAppModel.swift#L9330), [Android manifest](https://github.com/openclaw/openclaw/blob/main/apps/android/app/src/main/AndroidManifest.xml), [Control UI](https://docs.openclaw.ai/web/control-ui), [Gateway connection links](https://docs.openclaw.ai/platforms/mac/remote#open-the-mac-app-from-a-website).
