### Linux browser handoff

After confirming your extracted Antigravity app starts normally, place the following entry in `${XDG_DATA_HOME:-$HOME/.local/share}/applications/antigravity-link.desktop`. Substitute the installed executable's absolute path.

```ini
[Desktop Entry]
Type=Application
Name=Google Antigravity
Exec="/absolute/path/to/antigravity" %u
MimeType=x-scheme-handler/antigravity;
Terminal=false
```

```sh
update-desktop-database "${XDG_DATA_HOME:-$HOME/.local/share}/applications"
xdg-mime default antigravity-link.desktop x-scheme-handler/antigravity
xdg-open 'antigravity://'
```

[Google's Linux installation guide](https://antigravity.google/docs/getting-started) · [Desktop Entry execution keys](https://specifications.freedesktop.org/desktop-entry/latest/exec-variables.html)

## GitHub Copilot

- Desktop links open a reviewable session draft via `ghapp://session/new`. Pass an `owner/repo` repository, a prompt, or an independent custom agent. A branch or pull request number requires a repository, and those options are mutually exclusive. Supported modes are `plan`, `interactive`, and `autopilot`. GitHub documents an Allow step and review before submission. [GitHub Copilot deep links](https://docs.github.com/en/copilot/how-tos/github-copilot-app/open-with-deep-links) · [Official desktop releases](https://github.com/github/app/releases)

The package uses that wrapper when draft options are supplied and opens the ordinary Copilot web entry point when they are empty. [Launcher format](https://docs.github.com/en/copilot/how-tos/github-copilot-app/open-with-deep-links#launcher-url-format)
- VS Code 1.140 introduced `vscode://agents/new`, with optional `prompt` and a folder `workspace` URI. The documented composer preserves an existing draft and requires the user to submit. [VS Code 1.140](https://code.visualstudio.com/updates/v1_140) · [VS Code command reference](https://code.visualstudio.com/docs/configure/command-line#_prepare-a-new-agent-session-draft)

The documented GitHub Mobile flow opens new conversations from inside the app. A blank native Copilot launch or native draft prompt link remains unverified. [Copilot on GitHub Mobile](https://docs.github.com/en/copilot/concepts/copilot-surfaces/copilot-on-github) · [iOS association](https://github.com/.well-known/apple-app-site-association)
