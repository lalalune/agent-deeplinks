## OpenClaw catalog review

A stock AppImage 2026.11.10 follow-up used a saved Direct Gateway and authenticated as the native Linux UI for all three exact links. Public first-party catalog responses were replayed in a read-only isolated fixture. The Discord link showed the exact plugin detail, verified publisher, and **Install** and **Ask OpenClaw** controls. The Weather link opened the Skills catalog without showing the named item. With the Gateway’s experimental Templates flag enabled, Travel Copilot fetched the named package and release metadata. The metadata-only test stopped at the release archive request. The test left all install and run controls untouched. The tagged Linux skill handler navigates the Gateway WebView to a fresh document. The Skills loader captures the Gateway connection and selected agent for that document, and the page drops a detail request if either changes before it applies the route data. Later connection updates reload the list. This can explain the Weather result in the hosted run, where the Skills index rendered and the named item was never requested. A stock native build that opens the exact Weather review remains unverified.
